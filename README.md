# Supplementary material

Supplementary material and full code documentation for the following paper (ACCEPTED 2026):

* Vitali, D., Buono, R., Bi, T., Pickering, T., Eccleston, C., Keogh, E., Bianchi-Berthouze, N., & Williams, A. C. de C. (2026). *Day to day worry about interference from chronic pain: an ecological momentary assessment study.*

## Contents

The `docs/` folder contains six supplementary documents:

| File | Description |
|------|-------------|
| S1_MAR_explore_documentation | Missing data diagnostics and MAR assumption tests |
| S2_Mice_Imputation_documentation | Multiple imputation specifications and diagnostics |
| S3_Derived_Variables_documentation | Derived variables construction and validation |
| S4_Q1_model_documentation | Q1 model: worry-outcome coupling |
| S5_Q2_model_documentation | Q2 model: error-driven learning |
| S6_Simulation_study_documentation | Monte Carlo simulation study (ADEMP framework) |

## Reproducibility

All analyses were conducted in R. Source code is in `Code/`. Note: raw data are not included in this repository.
